## Featured Projects

<details open>
<summary><b>NextTrip - Travel Package Marketplace</b></summary>

<br/>

A full-stack travel marketplace connecting travelers, vendors, and admins across three dedicated React Native apps.

**Highlights**

- Advanced package discovery across destination, category, price, duration, rating, and amenities
- 20-screen vendor portal with package CRUD, Cloudinary images, itinerary builder, and seasonal pricing
- JWT auth with role-based access for travelers, vendors, and admins
- 19-screen admin portal covering approvals, moderation, bookings, reviews, categories, locations, and payouts
- Append-only audit logs and Expo push notifications across all user roles
- 95 REST endpoints, 17 backend service modules, and 22 PostgreSQL tables

**Tech:** React Native, Expo, Node.js, Express, TypeScript, Supabase, PostgreSQL, Cloudinary, TanStack Query, Zustand

</details>

<br/>

A production-grade healthcare app supporting appointments, doctor discovery, medicine ordering, lab tests, and video consultation.

**Highlights**

- Secure phone login with OTP expiry, resend cooldown, and JWT access/refresh tokens
- Doctor discovery with seeded data for 15 doctors
- Medicine ordering with 35 medicines and lab test booking with 37 lab tests
- Real-time 2-participant video consultation using WebRTC and Socket.IO
- Full healthcare workflow across 17 screens
- 21 backend APIs for users, consultations, search, profiles, and availability

**Tech:** React Native, Expo, NestJS, TypeScript, PostgreSQL, Redis, Socket.IO, WebRTC
